# Sreeja Reddy — Spider-Verse Portfolio

A responsive React + Vite portfolio with a black/red Spider-Verse-inspired visual style, animated entrance effects, clickable category panels, and draggable windows.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Add your photograph

Create a `public` folder in the project root and put your portrait inside it named:

`public/sreeja-photo.png`

The portfolio will show a styled placeholder until you add the photo. Use a clear, well-lit portrait with a vertical crop.

## Personal details to update

Open `src/App.jsx` and replace:
- `your-email@example.com` with your real email address.
- Project / internship descriptions if you want to adjust them to your exact resume wording.
- Add or remove skills based on the job you are applying for.

## Build for deployment

```bash
npm run build
```

The production website will be generated in the `dist` folder. You can deploy it to Vercel, Netlify, or GitHub Pages.
